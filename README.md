- The application is a native iOS app developed using SwiftUI that allows users to search and track stock symbols, view detailed stock information, and trade with virtual money. 
- The app integrates with Finnhub APIs to fetch real-time stock data, including quotes, company profiles, social sentiments, recommendation trends, and historical earnings data. 
- Key features include a personalized portfolio tracker, a favorites section for quick stock monitoring, and a trade sheet for buying and selling stocks with live updates on net worth. 
- The user-friendly interface incorporates animations, progress indicators, and a seamless navigation experience. 
- Additionally, the app leverages MongoDB for managing user portfolios, favorites, and cash balances, ensuring efficient data storage and retrieval.
- Tech stack used: SwiftUI, NodeJS, MongoDB, ExpressJS
